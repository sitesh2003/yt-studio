Free keys for the channels

Each key is free, with no card. Make the key on the provider's page, then add it on GitHub with the exact name below. Paste the key only into GitHub, never into a chat. Every key switches on by itself once it is saved.

How to add a key on GitHub (same for all)

  1. Open yt-studio, Settings, Secrets and variables, Actions.
  2. Press New repository secret.
  3. In Name, paste the name copied from this page. In Secret, paste the key from the provider.
  4. Press Add secret.

1. Groq (about 1,000 requests a day)

  1. Open console.groq.com/keys and sign in (Google sign-in is fine).
  2. Press Create API Key, give it the name yt-studio, and copy the key.
GROQ_API_KEY

2. OpenRouter (free models, including DeepSeek)

  1. Open openrouter.ai/settings/keys and sign in.
  2. Press Create Key, name it yt-studio, leave the credit limit empty, and copy the key. Do not add any credit.
OPENROUTER_API_KEY

3. Mistral (free experiment tier)

  1. Open console.mistral.ai/api-keys and sign in.
  2. If it asks for a plan, choose the free Experiment plan (it may ask for a phone number, not a card).
  3. Press Create new key and copy it.
MISTRAL_API_KEY

4. Cloudflare (illustrations and extra models): two secrets

  1. Open dash.cloudflare.com, API Tokens and sign in (free plan).
  2. Press Create Token, choose the Workers AI template, then Continue to summary and Create Token. Copy the token.
  3. For the account ID: open the dashboard home, open the menu beside your account name and choose Copy account ID (it is also shown on the Workers AI page).
CLOUDFLARE_API_TOKEN
CLOUDFLARE_ACCOUNT_ID

5. Kaggle (about 30 hours of free graphics card a week): two secrets

  1. Open kaggle.com/settings and sign in.
  2. Under Phone verification, verify your phone (needed for free graphics-card time).
  3. Under API, press Create New Token. A small file called kaggle.json downloads. Open it with Notepad: it shows your username and a key.
  4. Add the username as the first secret and the key as the second. Then delete kaggle.json from Downloads.
KAGGLE_USERNAME
KAGGLE_KEY

When you are done

Tell Claude "keys added". Claude checks which ones are present (only their names, never the values) and switches each one on.
