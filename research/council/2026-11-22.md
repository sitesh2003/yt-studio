## Rounds 3–4: the production system (discussion, both models answering each other)
**Joint decisions**
1. **Why It Works**: pause NEW production for 60 days (do not delete, rename or merge); move its strongest physics
   ideas into Ever Thought Why? as experiments; decide after 60 days on retention, shares and subs per 1,000 views.
   Effort split: ~70% Aakhir Kyun? (proven), ~30% Ever Thought Why?.
2. **Voice pace**: stop time-stretching (artefacts). Write shorter scripts (~85–95 words for 35 s) for the voice's
   natural pace. Benchmark Kokoro-82M (phoneme input via generate_from_tokens, speed setting) vs Chatterbox on the same
   30 scripts: pronunciation, naturalness, regeneration rate.
3. **Pronunciation dictionary**: display_text (captions) vs spoken_text (voice) vs phoneme_override; eSpeak NG for IPA.
4. **Hindi TTS**: benchmark AI4Bharat IndicF5 (MIT) and Indic Parler-TTS (Apache 2.0) vs Edge Swara on a fixed 30-line
   set (conjuncts, English terms, numbers, species names, real openings) – Hindi-capable ASR + human listening.
5. **Audio**: CC0 Freesound + YouTube Audio Library only. MusicGen weights are CC-BY-NC; Stable Audio Open has
   commercial limits – no generative music in monetised videos.
6. **Rendering**: EEVEE toon (Shader-to-RGB + constant ColorRamp + rim light; outlines via inverted hull or Freestyle)
   as default; benchmark the same 100 frames vs the current film look before trusting "2–4 min".
7. **Build this week (v1)**: JSON shot spec → deterministic Python builder; 3 templates (macro reveal, scientific
   cutaway, side-by-side), 3 camera behaviours (push-in, tracking, orbit), 3 word-triggered effects (impact shake,
   pop-in with overshoot, numeric HUD gauge), 2 reusable Actions; missing asset / bad timing stops the job.
   Success test: three visually different Shorts from the same templates with no new scene code.
8. **Evidence record per claim** (DOI, claim_supported, limitations, human_approved) from OpenAlex / Semantic Scholar /
   Crossref / Europe PMC; the LLM extracts, a person approves.
9. **Visual QA layers**: ffprobe/OpenCV (black frames, freezes, safe areas), Tesseract OCR (labels), faster-whisper,
   a vision model on sampled frames with a narrow checklist, then a person.
10. **Compute**: GitHub = coordinator (research, scripts, checks, assembly, upload); laptop = dependable renderer;
    Kaggle = opportunistic batch GPU (TTS benchmarks, VLM QA) – never a delivery dependency.
